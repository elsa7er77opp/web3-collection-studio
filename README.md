# Web3 Collection Studio

Web3 Collection Studio is a **local-first Windows desktop workstation** for preparing layered digital collections. It supports profile-driven PFP avatars, badges/gaming items, and custom digital art collections through a shared engine for canvas settings, ordered PNG layers, traits, weights, compatibility rules, local rendering, and metadata export.

The program does not connect to wallets, hold private keys, mint tokens, deploy contracts, publish collections, store assets in the cloud, or make investment claims. It prepares a local image and metadata package for a customer-controlled later minting workflow.

The approved architecture is maintained in `docs/architecture/Production-Architecture.md`. The first implementation target is a PFP 1:1 project profile, with Badge/Gaming and Digital Art profiles designed into the same domain model from the first commit.
