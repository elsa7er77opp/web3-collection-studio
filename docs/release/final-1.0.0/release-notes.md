# Web3 Collection Studio 1.0.0 Candidate Release Notes

This candidate consolidates the local-first Final workflow: visible native folder opening, safe backup recovery feedback and audit events, persistent traits/weights/Require/Exclude rules/workspace state, local composed PNG rendering, bounded render queue behavior, cancellation availability, and local relative-path metadata export.

The packaged identity has been replaced with the selected Flat Prismatic L. A post-package visual defect that embedded a checkerboard/white square into the mark was traced to the source PNG alpha, corrected in the asset pipeline, protected by automated regression tests, and reverified in the installed Login.[1] [2]
