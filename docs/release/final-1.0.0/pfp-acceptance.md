# Installed PFP Acceptance

The installed executable was used to create a local PFP collection, add a layer and local PNG trait through native dialogs, complete preflight, render a local preview PNG, and export local metadata. The retained metadata evidence references the output via a relative `outputs/preview-…png` path and contains no absolute project root.[1] [2]

The workflow remained local throughout: source images, render queue, output PNG, and metadata were stored under the collection project. No external publishing or Web3 network operation is part of this acceptance.
